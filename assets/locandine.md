# OnlyWinget promotional copy

Use the supplied screenshots and logo for posters, flyers, event banners, social cards and help desk handouts. OnlyWinget is a proprietary desktop application for Windows 10 and 11 (x64).

## Visual references

- Use navy or slate backgrounds with white text and blue accents. Use Segoe UI Variable, Inter or Montserrat for headings and body copy.
- Use the [OnlyWinget logo](logos/logo.png) and the screenshots for [Home](01-home.png), [Presets](02-packages-presets.png), [Search](03-packages-search.png), [WinGet updates](04-updates-winget.png), [Windows Update](05-updates-windows.png), [Sources](06-sources.png), [Activity](07-activity.png) and [Settings](08-settings.png).

## 1. Portrait poster (A4, A3 or larger)

**Manage Windows apps and updates from one desktop app.**

- **Reusable app lists.** Save your preferred packages as a preset, then select the packages you want to install.
- **WinGet search.** Find packages in the sources you enable, including custom sources.
- **App updates.** Review available WinGet upgrades and apply the selected upgrades in a batch.
- **Windows Update.** Scan for Windows updates and select the updates you want to install.

Use the Home screenshot as the main image. Place the presets, search and updates screenshots next to the corresponding features.

**Explore OnlyWinget on GitHub.** Use a QR code pointing to the [OnlyWinget repository](https://github.com/dennidalpos/OnlyWinget).

## 2. Folded flyer (A5 or tri-fold)

**Front.** Preparing another Windows PC? Build a reusable list of the packages you want to install. Show the Home or Presets screenshot.

**Back.**

1. Search the WinGet sources you enable or open a saved preset.
2. Select packages to install and check the results in Activity.
3. Check for WinGet and Windows updates from their respective pages.

OnlyWinget stores presets, settings and diagnostic logs on your PC. WinGet sources and Windows Update use network services. See the [privacy notice](../landing/privacy.html) for details.

## 3. Event roll-up (85 × 200 cm)

**One place to manage package lists and review updates.**

- Export and reuse package presets.
- Install or upgrade selected packages in batches.
- Review WinGet updates and Windows Update from the same application.
- Choose English or Italian in Settings.

Pair the Home screenshot with details from Presets and WinGet updates. Put the project QR code near the bottom.

## 4. Social cards and digital banners (1:1 or 16:9)

1. **Preparing a Windows PC?** Save a list of the packages you use. Use the Presets screenshot.
2. **Search the sources you enable.** Find a package, install it or add it to a preset. Use the Search screenshot.
3. **Review available updates.** Choose WinGet upgrades or check for Windows updates. Use the matching Updates screenshot.
4. **Explore OnlyWinget.** Available for Windows 10 and 11 x64, with an English and Italian interface. Point to the [OnlyWinget repository](https://github.com/dennidalpos/OnlyWinget).

## 5. Help desk handout

- Import and export package presets as JSON.
- Use WinGet for batch package actions. Installer behavior, prompts and privileges vary by package.
- View CPU, memory and disk metrics on Home.
- Enable and refresh configured WinGet sources. Adding, removing or resetting sources requires elevation.
- Review session activity and export diagnostic logs.
- Choose between an NSIS installer and a self-contained portable x64 package.
- Refer to the [proprietary license](../LICENSE) for terms.
